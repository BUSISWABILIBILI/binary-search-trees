# Binary Search Trees

A balanced Binary Search Tree implementation built with JavaScript for The Odin Project.

## Features

- Build balanced BST from an array
- Remove duplicate values
- Insert nodes
- Delete nodes
- Search values
- Breadth-first traversal
- Depth-first traversals
- Height and depth calculations
- Balance checking
- Tree rebalancing
- Pretty print tree structure

## Traversals Included

- Level Order
- In Order
- Pre Order
- Post Order

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open `index.html` in the browser and open the developer console.
